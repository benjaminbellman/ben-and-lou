# Ben & Lou's Wedding Adventure

A Pokemon-style pixel art RPG minigame for our wedding! Explore the venue, talk to guests, complete quests, answer trivia, and sign the guestbook.

**Play now:** https://benjaminbellman.github.io/ben-and-lou/

## How to Play

- **Arrow keys / WASD** - Move
- **Space / Enter / Z** - Interact / Advance dialogue
- **Q** - Quest log
- **Mobile** - Touch controls (D-pad + action button)

## Features

- Top-down pixel art overworld with grid-based movement
- 5 NPCs to talk to (Lou, Ben, Best Man, Maid of Honor, Grandma)
- 4 quests to complete
- Trivia battle about the couple
- Guestbook for leaving messages
- Auto-save progress
- Mobile-friendly with touch controls

## Tech

Built with [Phaser 3](https://phaser.io/) - all pixel art assets generated programmatically (no external image files needed).
